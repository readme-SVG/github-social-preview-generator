# RepoCard Studio — 30 templates

All cards use the same Astro repository snapshot (October 7, 2026), the Slate palette, and Showcase statistics. Stars and forks are randomized decorative counts; select GitHub data in Content to use actual repository counts.

The Composition lab adds generated designs beyond these 30 templates.

[Desktop export example](repocard-desktop.png) — the full-width card with the original 77px safe spaces above and below.
